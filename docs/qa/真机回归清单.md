## 为什么要这份清单

客户踩的坑几乎全在「环境」而不是「功能逻辑」：系统代理、TUN 全局出口、10808 端口位次、
TikTok 直播 WAF 等待、CDN 裸请求返 204、ffmpeg 不读系统代理。这些一条都无法被静态断言捕获。
门禁保证「不倒退」，这份清单保证「真能用」。

## 一、四种必跑环境

| # | 场景 | 前置条件 | 操作步骤 | 通过判据 |

| 1 | 系统代理 | Clash Verge 开启「自动配置系统代理」，混合端口 10808 在前 | 启动软件 → 设置页「完整体检（实测网络）」→ 查看出口模式；再跑一次 TikTok 直播状态查询 | 体检显示 `proxy` 且「已实测」；状态查询能返回明确结果，不是「状态未知」；`10808` 先于 `10809` 命中 |

## 三、作者侧：如何真正收到数据

客户端源码里**没有任何写死的服务器地址**，默认就是纯本地记录。要启用自动上报，需同时满足两个条件：

1. 客户机 `config.json` 写 `diag_endpoint`（只允许 `https://`；本机自测可用 `http://127.0.0.1:*`），
   或设环境变量 `TRAFFIC_DIAG_ENDPOINT`；
2. 客户在「设置 → 系统档 → 匿名故障摘要」主动勾选开关。

接收端只需接受一个 POST，请求体格式：

```json
{"events": [{"ts": 1763212345, "ver": "1.28.7", "edition": "full",
             "anon_id": "…16位随机…", "kind": "failure",
             "step": "failure_dialog", "code": "录制失败",
             "egress": "direct", "result": "fail"}]}
```

返回任意 2xx 即视为成功，客户端会清掉已发送的待发行；失败则保留到下次，不做重试风暴。
`anon_id` 与机器无关，只用于区分「同一台安装」的事件序列。

> ⚠ 启用前必须先完成隐私告知：设置页已写明字段清单。不允许在客户不知情的情况下
> 由外部脚本直接改 `config.json` 打开开关。

## 五、P1 发版链可重复 / 可回滚（2026-11-16）

**判据**：发版中途失败或断电后，用同一条命令重跑，不升两档、不需人工判断该不该改版本号。

### 已由门禁覆盖（`tools/_validate_release_chain.py`，52/52，沙盒真跑 main()）

| 场景 | 断言 |
|---|---|
| 上传 COS **之前**失败 | `branding.py` + `installer.iss` 按字节整份回滚；重跑仍是 `1.28.7 → 1.28.8`，不升两档 |
| 上传 COS **之后**失败 | 源码版本保持新值（不回滚），状态保留 `published=true` |
| 重跑同一条命令 | 自动转 `--no-pack` 续跑，`old=new`、不重新打包、不重跑 24 套门禁 |
| 断电把源文件写成全 NUL | 预检直接中止，并给出「删 `.git/index` + `git read-tree HEAD`」的恢复指引 |
| 状态文件自身损坏 | 改名留证、按全新发版处理，不静默吞掉 |
| `--dry-run` | 纯读：不写状态、不碰源文件 |
| 分界线位置 | `mark_published()` 必须紧跟上传成功之后；挪到别处门禁即红 |

### 真机仍待验证（需要一次真实发版，本机尚未执行）

1. 打包中途 `Ctrl+C` 或进程被 SIGTERM —— 日志末尾不等于真停，看 `installer_output/version.json` 与状态文件再决定。
2. `--no-pack` 手动续跑（未带 `--with-extras`）后，四件套是否仍需单独补。
3. `--with-extras` 全链路：免费版打包 → EdgeOne 自有域名部署（真机 PowerShell 全路径、禁 `-a overseas`）→ COS 镜像 → 发卡工具按需重建。**本轮只做了静态接线与干跑，没有真部署**（不发版）。
4. 部署后 2 分钟内的终检时序（`--noproxy '*'` + 绝对路径 curl、200≠正常、直链验 206）。

> 手工兜底：若确认**线上尚未发布**而状态文件卡住，删掉 `installer_output/.release_state.json` 即可按全新发版重跑；若线上已发布，不要删、也不要手工回退版本号，直接用同一条命令续跑。
